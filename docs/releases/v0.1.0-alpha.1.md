# v0.1.0-alpha.1

The first release of plgrid-llmlab-hpc-burst: a control plane on your own host that serves models on Cyfronet's Athena behind one LLMLab-compatible endpoint. It's an alpha. It's tagged before alpha graduates, by the owner's decision of 13 Nov 2026 (HBEP-15, Releases), and the criteria still open are listed below.

Start with [the quickstart](../quickstart.md). From the archive, unpack it, check `SHA256SUMS`, and follow the steps with the archive's `bin/`, `agent-builds/`, `config/crd/`, `profiles/` and `examples/`. No clone is needed.

## Platforms measured

All on Athena, in host-dialed mode: the control-plane host dials each job through the login node, so no compute node reaches the host. Every row ran on a commit whose shipped code (the Go packages the four binaries are built from, the pins, CRDs, profiles and examples) equals this release's: pre-staging, row A and GPU accounting on `5ba3a100`, and row B on ROW_B_COMMIT after a fix to its test harness, which isn't shipped (HBEP-15, Releases).

| Row | What it shows | Result |
|---|---|---|
| Pre-staging (`alpha-athena-now-stage`) | the image and checkpoint staged to the job, then found warm | Pass: the image and all 10 checkpoint files present and matching |
| Row A (`alpha-athena-now-serve`) | a deployment served through the front, with attribution, the engine gauges, and a killed engine restarted at the worker rung | Pass: 7,000 of 7,000 tokens at 199 tokens/s, uncut; every response attributed; a killed engine ready again in 1 min 20 s; after the deployment's delete, its job ended within the row's wait |
| Row B (`alpha-athena-now-nooverlap`) | the one-slot handover: a stream in flight at the drain start finishes uncut, and the successor starts after its predecessor leaves the slot | ROW_B |
| GPU accounting (`gpu-accounting-athena-now`) | the accounting record's GPUs equal the job's | Pass: the record's GPUs equal the job's 1 |

They ran on `plgrid-now`, a one-GPU, one-hour partition on the same A100 nodes as `plgrid-gpu-a100`. A row there counts for `plgrid-gpu-a100` when it runs one job of one GPU within the hour (#373). The per-row posts are on [issue #145](https://github.com/groundnuty/plgrid-llmlab-hpc-burst/issues/145).

## Alpha criteria still open

- **On `plgrid-gpu-a100`:** the no-cut handover with two jobs at once (HBEP-5, HBEP-7), and the one-hour tunnel run (HBEP-6). Neither fits `plgrid-now`, and Athena's A100 queue hasn't reached them. Alpha graduates, and a later alpha tag follows, when they pass.
- **On Helios:** every Helios criterion is beta's, to run when the GH200 nodes return (#373).

## The HBEPs

HBEP-1, 3, 4, 5, 6, 7, 8, 11 and 15 are `implementable`, and HBEP-2, 9 and 10 `provisional`. None is at a stage yet: their alpha status PRs follow graduation (HBEP-1).

**Beta features in this release, opt-in and off by default:**
- an Envoy router in front of an Instance's workers (`up --instance-router envoy`; Envoy's builds aren't in the archive and are fetched with `hack/fetch-envoy.sh`);
- several workers per Instance (`workersPerInstance`, which needs the router);
- a separate tunnel for large non-streamed replies (`up --bulk-path`).

Each is tested in CI on loopback, not on a cluster.

## Stated limits that still apply

- **Short partitions host short tests only.** `plgrid-now` serves under `profiles/athena-now.yaml`, for tests of up to an hour, not real serving.
- **Tunnels per front:** keep a front at or below 600 tunnels in direct mode and 300 in host-dialed mode, the largest measured (HBEP-6, open question 11). No code enforces it.
- **A host-dialed relay's ssh stalls its streams at each rekey,** about 100–180 ms about once per GiB, on OpenSSH 9.6p1 with chacha20-poly1305 (HBEP-6, Risks).
- **The bulk path protects token streams only while the path's bottleneck buffer drains in under about 85 ms,** to be read on the real path before beta (HBEP-6, open question 12).
- **A request written into a pooled connection in the moment its tunnel or worker dies** gets 502 and isn't resent, since nothing written is replayed (HBEP-5, HBEP-6).
- **Envoy needs glibc 2.30 or later on the compute node.** Athena's login node runs 2.34; Helios's runs 2.28 (HBEP-5).
